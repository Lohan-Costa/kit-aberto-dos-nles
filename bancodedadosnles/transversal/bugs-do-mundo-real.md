# Bugs do mundo real — o que um app errou e todos os outros têm de conferir

Criado em 2026-10-08, a pedido do autor: "uma relação de bugs capturados em mundo real para correção
em todos os NLEs". Um bug achado num app (ou num NLE) quase sempre é uma CLASSE de erro que os
outros apps também podem ter — o mesmo molde, a mesma conta, o mesmo estado do NLE. Aqui fica a
ficha do bug com a **regra geral** e, por app × NLE, em que pé está.

**Dados (máquina):** [`bugs-do-mundo-real.json`](bugs-do-mundo-real.json) — é a fonte; este arquivo resume.

## Como usar

- **Abrir uma sessão num app/NLE** (inclusive para "ver se o bug do Premiere acontece aqui"): ler as
  fichas com `conferir` para aquele alvo e dizer ao autor, em uma linha, quantas são. Conferir é
  rodar o "como conferir" da ficha; o resultado vira `corrigido` (com o onde e a data), `visto` (o bug
  estava lá: corrigir e registrar) ou `nao_se_aplica` (com o porquê).
- **Achar um bug em produção real:** depois de corrigir, criar a ficha (`B` + número), com sintoma
  em linguagem de editor, causa, regra geral e o estado de CADA alvo conhecido (`conferir` quando não
  se sabe). A skill `/ciclo-media-dev` lembra os dois passos.
- Estados: `corrigido` · `conferir` · `visto` · `nao_se_aplica`.
